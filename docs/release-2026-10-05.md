# Release note — 2026-10-05

Cette révision de production regroupe les durcissements validés de NOVA et de Smart Import.

- NOVA : modèle Gemini stable par défaut avec repli automatique sur modèle de secours lors des erreurs transitoires.
- Smart Import : jusqu'à 5 fichiers par lot, traitement indépendant, erreurs d'upload visibles et types d'images résolus même lorsque le navigateur ne fournit pas de MIME.
- Revue : modification et suppression des éléments extraits avant validation, avec revalidation obligatoire après modification.
- Aucune migration Supabase ni élargissement RLS/Storage dans cette révision.

CI et E2E doivent rester les portes de sortie avant promotion.
